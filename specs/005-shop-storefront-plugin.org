* Problem

The agent needs a *read-only* view of a real shop's order queue (first
deployment: the Owner's shop client, name withheld) without any bespoke
integration: one plugin must
serve any REST-shaped storefront, and no client code, client branding or
client data model may enter this tree (purity law).

* Requirements

1. ~plugins/shop/~ ships:
   - ~adapter.py~: a ~StorefrontAdapter~ ABC plus a REST implementation. The
     shop's ~base_url~, path layout, filter names, status vocabulary and page
     shape are all ~plugins.entries.shop.settings~ in the profile's
     ~config.yaml~ — configuration, not code.
   - four tools: ~shop_queue~, ~shop_orders~, ~shop_order~, ~shop_catalog~;
   - ~hermes shop~ (subcommand) and ~/shop~ (slash command).
2. Structural rules (not advisory):
   - *Money never routes through a model.* Every number a tool returns is the
     shop's own API field; the only arithmetic in the plugin is counting
     rows, and each count carries provenance (~source: api~ for the shop's
     total vs ~source: page~ for a tally over the page the model is looking
     at).
   - *Read-only by construction.* No write path exists, and none lands
     before an approve-before-send gate exists. Outward-facing social
     channels stay out of scope.
3. Secret handling: the token is read through ~agent.secret_scope~ at *call
   time*, never at import (one process serves many profiles; an import-time
   read would silently bind whoever launched it). Adapters cache per
   (settings, token) so a second profile cannot inherit the first's
   connection.
4. The tools exist only for a profile that configured a shop: ~base_url~ set
   *and* the secret scope holding the token.
5. Tests: ~tests/plugins/test_shop_plugin.py~ — 23 tests, green via
   ~scripts/run_tests.sh~ (never bare pytest; CI parity).
6. Commit: ~51e1d196c8~ (~feat(shop)~ on ~ai/light-core~), authored
   Qwen3.8-Flash with the standard trailers
   (~Co-authored-by: z.ai-agent <z.ai-agent@z.ai>~ and
   ~Co-authored-by: Khalid Rafi <khaalidrafi@gmail.com>~).
7. Hygiene verified before commit: no secrets in the diff; no
   client-specific hardcoded data; ~__pycache__~ ignored.

* Acceptance criteria

1. ~scripts/run_tests.sh tests/plugins/test_shop_plugin.py~ → 23/23 green

4. Token read happens inside the call path, not at module import (code
   review of ~adapter.py~).
5. Handoff review entry point: ~plugins/shop/adapter.py~ — "check that no
   number is computed from anything but the shop's own fields"
