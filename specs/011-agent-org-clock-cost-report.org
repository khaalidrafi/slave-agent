* Problem

agent-org already files the data — closed ~CLOCK:~ ranges per exchange,
~:RESPONSE:~ seconds, per-file ~:Provider:~/~:Model:~/~:Tokens:~/~:Cost:~ —
but nothing reports over it. The Owner ordered "Start working on the special
design, PLEASE": build the brainstorm's top item, "seconds AND dollars per
model", without violating the design guardrails (never touch org-clock
state; on-demand only, no timers).

* Requirements

1. ~M-x agent-org-clock-report~ (~(defun agent-org-clock-report (&optional only-this)~): opens an org-mode report buffer (name shaped like
   ~*agent-org clock report*~) containing:
   - a hand-rolled per-chat legend table with columns
     ~Chat | Provider | Model | Turns | Response | Tokens | Cost~ — one pass
     per transcript over the first drawer's ~:Provider:~/~:Model:~/~:Tokens:~/~:Cost:~
     (cost shown verbatim as the filed string, no arithmetic) plus
     ~:RESPONSE:~ seconds summed; a totals row for Turns/Response/Tokens;
   - a ~#+begin: clocktable~ dynamic block whose ~:scope~ is the LIST of the
     project's ~.agent-org/*.org~ transcript files (~:maxlevel 1~ —
     exchanges are level-1 headlines), refreshable with ~C-c C-c~ via
     ~org-update-all-dblocks~.
2. Prefix arg = ~only-this~: scope the report to the current session's
   transcript alone (mirrors ~agent-org-resource-monitor~'s ONLY-THIS).
3. Guardrails (each pinned by a test):
   - *never enters org-clock machinery*: the report must not call
     ~org-clock-in~/~org-clock-out~/~org-clock-load~/~org-clock-resolve~ —
     it only reads closed ~CLOCK:~ lines through the clocktable writer;
   - *one project's directory only*: only files under the resolved
     ~agent-org-transcript-directory~ (an absolute binding is respected —
     no CWD leak; a transcript placed elsewhere is not reported);
   - *on-demand*: no timers, no hooks;
   - nothing to read → ~user-error~ saying so.
4. Reuse house idioms: the resource-monitor's table helper
   (~agent-org--resource-table~), the report-buffer conventions, the
   transcript fixture helpers; a small duration formatter for
   seconds → ~H:MM:SS~ shaped like the monitor's formatters. Emacs 30.2
   facts relied on: ~:scope~ accepts a list of files
   (~org-dblock-write:clocktable~ in org-clock.el); the clocktable writer is
   autoloaded (a plain ~(require 'org)~ fixture worked).
5. Tests (names as landed): ~test-agent-org-clock-report-tables-the-clocks-a-project-files~, ~…-reads-one-projects-directory-only~, ~…-never-enters-org-clock-machinery~, ~…-prefix-arg-answers-one-chat~,
   ~…-with-nothing-to-read-says-so~.
6. Docs: a short README.org section and an AI-REVIEW.org note were planned
   with the feature.
7. Working discipline forced by the box: the shared
   ~tests/test-agent-org.el~ was being edited by a concurrent session, so
   the tests were validated in a standalone copy first
   (/tmp/ao/test-clock-report.el with ~(require 'ert-x)~ and
   ~(setq load-prefer-newer t)~), before any move into the shared file.
