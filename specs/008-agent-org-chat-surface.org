* Problem

The Owner's standing request list for the agent-org Emacs package:

1. Remove the "agent-org: " prefix from chat buffer names; format
   "Qoder:agent-org [SESSION_ID]".
2. Transcripts should live under a project's ~.agent-org/~ directory.
3. Tool calls should be inside ~:tool:~ drawers.

The Org drawer spec forbids headlines inside drawers, so the previous
rendering (tool calls as ~** KEYWORD title~ subheadings) could not simply be
wrapped; the shape had to become drawer *lines*. The AGENTS.md statement "Tool
calls are HEADLINES, not a drawer" was therefore stale the moment the Owner's
order landed and had to be rewritten in the same change.

* Requirements

1. Buffer names: ~<Provider>:<project> [<session-id>]~, no package prefix —
   commit ~3eebe08~ "Names: a chat buffer is 'Qoder:agent-org [sid]', no
   package prefix" (committed by a concurrent agent on ~ai/quickstart~).
2. Transcripts: one Org file per session, mirrored at turn boundaries, under
   a per-project ~.agent-org/~ directory — commit ~b7b882f~ "Transcripts: one
   .agent-org/ per project, and the suite stops writing". The directory name
   is ~agent-org-transcript-directory~ (default ~.agent-org~); projects may
   want it in their ~.gitignore~.
3. Tool calls: ONE ~:tool:~ drawer per agent turn, one line per
   toolCallId — implemented in ~agent-org-buffer.el~ (~:tool:~ rendering;
   the transcript records the renderer around line 991 of that era) with
   tests asserting ~^:tool:$~ occurrence counts (tests of that era at lines
   437–604).
4. AGENTS.md updated to match: "Tool calls: ONE ~:tool:~ drawer per turn,
   one item per toolCallId" (plus the FOLD-is-default drawer convention) —
   the doc fix is part of the change, per the repo's own convention that
   moving a symbol means fixing its docs.
5. A concurrent agent was committing to the same branch and files; commits
   ~1–3~ above were landed by that agent, and shared files
   (~tests/test-agent-org.el~, ~agent-org.el~) carried interleaved in-flight
   hunks. Attribution hygiene ("DON'T commit changes made by other sessions
   as yourself") shaped who committed what.
